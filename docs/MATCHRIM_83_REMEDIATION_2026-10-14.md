## Winerim Scope

Native label/menu details and Bodega can request the original Winerim record. Lookup is on demand against the existing first-party recommendation proxy using a neutral3/3/3/3/3 query, never the person's profile. It is a partial response, not exhaustive catalog search. Missing record, exact producer, year or qualifier remains pending. The neutral ranking/percentage is not reused as personal affinity.

Original fields are displayed from the matched API record: name, producer, vintage, region and grapes. No AI biography or sensory attributes are invented to fill gaps. A local search-wines UUID is not an official ID. Manual identity edit removes the previous source and score. Native legacy OCR no longer creates an original-fiche link from a local UUID; hosted-web behavior is left alone.

Live neutral API readback: HTTP200,30 records,1184ms; a second field-path check200/30,1009ms. The response has id and slugname, but no publicUrl/public_url. Direct Duo55963 URL opened the Library list, not its detail. Visible Ver detalle for Manzanilla La Gitana opened an actual original fiche at278688 with producer/grape/tasting content. These do not prove that every recommendation ID binds to a public Library page. The candidate therefore hides unverifiable links and shows original API metadata only. Full original-fiche navigation remains an upstream contract/mapping gate.
