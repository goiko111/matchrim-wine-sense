## Changes Integrated

1. Preserve independent dense-scene regions when a container box overlaps bottles; retain per-region retry, correction, discard and traceability. This does not establish exhaustive detection recall.
2. Reject grape/category-only and descriptive placeholder identities before affinity/sensory enrichment. A visible producer can disambiguate a generic grape; unseen producer text cannot manufacture an identity.
3. Keep canonical lookup strict about producer, cuvee and observed vintage. Provider search results without catalog IDs are not promoted to verified identity. Query the name column by name, then validate producer evidence on candidates, instead of requiring name plus producer in one column.
4. Replace misleading recognition wording with `Nombre leido / revisa la referencia`; display `Sin datos` for missing affinity. Manual identity correction invalidates stale affinity.
5. Fix a blank-results state when all OCR items are rejected: show a useful explanation and retry instead of a success state with zero cards.
6. Integrate native six-step guide, bottom-menu aiRIM with speech-bubble icon, safe-area/privacy fixes, account-local isolation, consent-aware training evidence and safe auth return handling from the prior sealed work.
7. Keep menu cards progressively disclosed, numbered image pins, individual explanations, comparison 2-5, glass/bottle budget and currency checks. Do not treat all bottles as one wine.
8. Prevent nearby distinct cuvees from merging just because winery tokens overlap. A failing regression merged Barbaresco and Barolo into one; the corrected client preserves both. Existing OCR-variant/price-conflict contracts still pass.

Chronology matters: the full 25-scene run preceded the final placeholder filter, versioned catalog routing, empty-state, name-query and cuvee-dedup fixes. Five/focus/negative runs tested later snapshots; only the first original menu was rerun on the final client. **There is no final-source aggregate 25-scene accuracy score.** Offline replay uses the same recorded provider items and is not independent validation. Live provider responses are nondeterministic, so the first-menu improvement alone is not a controlled causal estimate. Its legacy runner marked PASS despite the recovered 500; this is not a zero-error release pass.

Independent-25 latency: median 15.720 s, max 92.061 s; one catalog HTTP 500 before correction. Original-five latency: median 42.031 s, max 85.893 s, zero HTTP errors or horizontal overflow. Counting identity percentages as affinity was a QA instrumentation defect and was corrected before the five-photo rerun.

`annotation-review.json` is additive agent review of three fixtures, including the incorrectly labelled mixed-menu negative (17/17 extracted names). Originals were not rewritten. It is **not an independent human adjudication**, and no canonical bottle-ID/producer/vintage/format ground truth was approved.

## Remaining Gates

1. **P0 technical:** canonical identity/recall in dense scenes, duplicate rows in the first personal menu, and excessive dense-scene latency. These are quality failures, not an Apple-account or provider-quota excuse.
2. **P0 evidence:** a second qualified reviewer must validate bottle-level boxes, producer/cuvee/vintage and illegible cases. Unreadable labels require a closer source image, not invented ground truth.
3. **P0 intelligence:** validate personalized ranking against independent human taste/service judgements and resolve the earlier synthetic calibration failures before claiming recommendations are correct.
4. **P1 QA:** complete the unapproved native/permission/account/network/VoiceOver workflows and rerun the immutable 25-scene benchmark on one final source revision after recognition changes.
5. **Release:** only then verify the current App Store Connect build number/channel and upload. Signing works locally; no current agreement or quota blocker was demonstrated. There is no single owner click that makes the present recognition results acceptable.

Step status: 1 partial, 2 implementation improved but intelligence validation open, 3 candidate integrated, 4 substantial functional/real-image evidence with explicit gaps, 5 withheld by quality gate. A global completion percentage would conceal these different gates; this is not 100% done.
